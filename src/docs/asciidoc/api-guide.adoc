== Overview

This API accepts 3D building data (polygonal outlines with height ranges and floors) and determines which building and floor a given point falls within. The locate query uses a two-stage spatial filter.

== Locate a point

`POST /api/locate`

Determines which building and floor contain the given (x, y, z) point. Three outcomes are possible: the point is on a specific floor, the point is inside a building but not on any floor, or the point is not inside any building.

== Locate strategy

The locate endpoint supports two spatial filtering strategies, switchable at runtime without restarting the application.

- **JAVA** (default) -- height filter in the database, ray casting in the Java domain layer. Clean and testable, but does not scale beyond ~100K buildings.
- **POSTGIS** -- `ST_Contains` with a GIST spatial index pushed entirely to PostGIS. O(log N) regardless of dataset size.
